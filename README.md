# 🛒 CampusCart

CampusCart is a college-focused marketplace where students can buy, sell, and exchange second-hand items within their own campus.

Instead of using general marketplaces, CampusCart helps students connect with trusted people from their college community.

---

## 🎯 Project Idea

Students often have unused items like:

- 📚 Books
- 💻 Electronics
- 🧮 Calculators
- 🚲 Bicycles
- 🛏️ Hostel Items
- 🎮 Gaming Accessories

CampusCart provides a simple platform where students can list items and find useful products at affordable prices.

---

## ✨ Current Features

### 👨‍🎓 Student Features

- Browse available products
- View product details
- Search products
- Add items to wishlist
- Sell items through a listing form

### 🖥️ Frontend Features

- Responsive homepage design
- Product cards
- Interactive modals
- Dynamic product details popup
- Wishlist interaction
